## How to use my dotfile :

## 1. clone the repository -




 git clone https://github.com/ZeromXe27/Zshell.git

## 2. make a .config file -




 mkdir -p ~/.config

## 3. copy the cloned .config file to new file -




 cp -r .config/* ~/.config/
